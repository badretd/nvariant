# Миграция выпуска №1 «Опыт прошлых лет»

Актуальная редакция перенесена 30 июля 2026 года из `source-imports/opyt-proshlyh-let-v2/Опыт прошлых лет v2.md`. Файл `Сюжет.md` использован как источник доступной интерактивной схемы.

Публичный порядок:

1. «Мне всегда хотелось быть главным»;
2. «Управление командой»;
3. «6 ролей»;
4. «Сериал на двоих»;
5. «Когда ты не главный»;
6. «Основание N-варианта».

Имран Бадретдинов указан автором пяти материалов, Клим Гуляев — автором «6 ролей» и актёром «Исповеди школьника», Самад Юсупов — независимым экспертом. Биографии не дополнялись сведениями вне импорта.

YAML под изображениями перенесён в единый реестр. Старые версии `is-demo-shot`, `hi-imran`, `hi-klim` заменены; `vs-edit-process` удалён. Активные файлы названы по media ID. Обложка и три профильных портрета зарегистрированы отдельно.

Закрытые пересказы реализованы через `details`, сюжет — через статически доступное дерево развилок, LOST MEDIA — через доступный диалог, а инструкция Bandcamp — через ленивый embed с обычной ссылкой. Декоративные Google-поля заменены прямыми очищенными ссылками.

Архив материалов использует тот же нормализованный текст, что и глобальный поиск. Параметры: `q` для текста и `tags` для списка тегов; несколько тегов объединяются по AND.

Перед публикацией обязательны `npm run lint`, `npm run typecheck`, `npm test`, `npm run validate`, `npm run validate:media` и `npm run build`.
